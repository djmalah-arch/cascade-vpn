# Название сервиса при установке

- Проверены install.sh, портал, подписки, шаблоны и настройки Docker на жёстко заданные названия.
- Воспроизведены два дефекта тестами: чужой бренд в инструкции подключения и отсутствие переименования существующего Happ-хоста.
- Название Happ-хоста, инструкции, подсказки, вход и скачиваемый AWG-файл используют BRAND. HTML экранирует название, имя файла передаётся в UTF-8.
- Старые Happ-шаблон и правило переименовываются без изменения UUID; хост находится по UUID шаблона или прежнему имени. Сохраняется совместимость существующих установок.
- Установщик показывает выбранное название в итоговых доступах; новый стандартный логин панели — admin. Сохранённые логины не меняются.
- Убраны брендовые названия из сообщений обнаружения чужой установки.
- Технические пути, имена Docker, CLI, метки и имена служебных файлов остаются стабильными для совместимости. GeoVPN остаётся значением BRAND по умолчанию и идентификатором миграции старых данных.
- Проверка: 33 unittest (Windows: один Unix-тест пропущен), включая альтернативный бренд с кириллицей и HTML-символами; bash -n установщика. Чистая установка ОС в рамках этой правки не выполнялась.
