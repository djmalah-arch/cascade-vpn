# Cascade VPN

Каскадный VPN с раздельной маршрутизацией для пользователей из России:

```
 Клиент ──🔒──► Входной сервер в РФ ──🔒──► Выходной сервер за границей ──► интернет
 (Hiddify, Happ,   ├─ российские сайты — напрямую
  Amnezia,         ├─ YouTube — с российского IP (без рекламы), обход DPI
  Telegram)        └─ остальное — через выход (основной + резервы по приоритету)
```

- **Протоколы:** VLESS + Reality и Hysteria2 (Hiddify/Happ/sing-box), AmneziaWG 2.0 (Amnezia), MTProxy (Telegram).
- **Всё на одном порту 443:** посетитель-браузер видит обычный сайт с настоящим сертификатом, VPN-клиент — VPN.
- **Портал:** заведение пользователей (группы, администратор/модератор), персональные страницы с инструкциями и QR,
  зеркало установщиков приложений, мониторинг, журнал и лог ошибок.
- **Балансировщик выходов:** приоритеты (основной → резерв 1 → резерв 2…), сторож переключает при отказе за 10–20 с;
  добавление/удаление выходных серверов из веб-интерфейса одной кнопкой.
- **Всё в Docker.** На хосте — только Docker и настройки ядра (BBR, ip_forward).
- Подробнее для руководителя: [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md), для администратора: [docs/OPERATIONS.md](docs/OPERATIONS.md).

## 1. Установка входного сервера (Россия)

Требования: чистый VPS в РФ, Ubuntu 24.04/26.04 или Debian 12, 1 vCPU / 2 ГБ RAM, желательно IPv6;
домен (A-запись → IP сервера), свободные порты 80/tcp, 443/tcp+udp.

```bash
apt-get update && apt-get install -y git
git clone https://github.com/djmalah-arch/cascade-vpn.git /opt/cascade-vpn
cd /opt/cascade-vpn && ./install.sh
```

Установщик спросит (Enter — значение по умолчанию / сгенерировать):

| Вопрос | Пример |
|---|---|
| Публичный IPv4 сервера | определяется сам |
| Домен входного сервера | `vpn.example.com` (для теста: `1-2-3-4.sslip.io`) |
| Название сервиса | `GeoVPN` |
| Логин / пароль администратора Remnawave | `geoadmin` / сгенерировать |
| Пароль **администратора** портала | всё: пользователи, серверы, панель |
| Пароль **модератора** портала | только группа `work`, серверы — просмотр |
| UDP-порт AmneziaWG, TCP-порт MTProxy | случайный / 9443 |

Без вопросов (автоматизация): `DOMAIN=vpn.example.com ADMIN_PASS=... MOD_PASS=... ASSUME_YES=1 ./install.sh`

В конце установщик **выводит все доступы** (секретная ссылка входа, пароли, логин панели) и сохраняет их в
`/root/geovpn-credentials.txt` — перенесите в менеджер паролей и удалите файл с сервера.

## 2. Добавление выходных серверов (за границей)

Ничего вручную ставить не нужно:

1. Купите чистый VPS вне РФ (Ubuntu/Debian, root-вход по паролю; желательно с IPv6 и у разных хостеров).
2. Портал → **`/admin/servers` → «Добавить сервер»**: название, IPv4, IPv6 (можно подсеть из панели хостера), приоритет, root-пароль.
3. «Добавить и установить» — портал сам подключится по SSH (если IPv4 заблокирован в РФ — по IPv6), поставит Docker и ноду,
   закроет порт управления для всех, кроме входного сервера, создаст ключи и включит сервер в цепочку. Пароль не сохраняется.
   На выходе всё тоже в Docker (`/opt/remnanode`): контейнеры `remnanode` (xray) и `geovpn-fw` (файрвол порта управления);
   на хосте — только Docker и BBR.

Приоритет 1 — основной, 2 — первый резерв и т. д.; одинаковый приоритет — нагрузка делится.
Сменил IP у хостера → кнопка «Адрес…». Удалить сервер → «Удалить…» (с root-паролем нода удалится и с самого сервера).

## 3. Пользователи

Портал `/admin` → «Новый пользователь» → «Копировать» → отправить пользователю приглашение со ссылкой на его персональную страницу.
Там он выбирает приложение (Hiddify — рекомендуем, Happ, Amnezia, прокси для Telegram), скачивает его с вашего сервера и подключается по QR/кнопке.

## 4. Полезные команды (на входном сервере)

```bash
cd /opt/cascade-vpn
docker compose ps                                          # состояние всех служб
docker exec geovpn-portal geovpn status                    # службы, YouTube, выходы
docker exec geovpn-portal geovpn set-password admin 'NEW'  # пароль администратора (users — модератора)
docker exec geovpn-portal geovpn apply-direct              # применить data/portal/direct.json (игры мимо VPN)
docker exec geovpn-portal geovpn backup                    # бэкап сейчас (автоматически — ежедневно, data/portal/backups)
docker compose logs -f portal                              # лог портала
git pull && docker compose build && docker compose up -d   # обновление
```

## Структура

| Путь | Что |
|---|---|
| `install.sh` | установщик входного сервера |
| `docker-compose.yml` | все службы: Remnawave (панель, БД, Valkey), нода xray, Caddy, AmneziaWG, sing-box, zapret, MTProxy, портал |
| `portal/` | портал (Python): `app.py` (админка, страницы, AWG, MTProxy, мониторинг, бэкапы), `servers.py` (выходы, балансировщик), `cli.py` (команда `geovpn`), `bootstrap.py` (первичная настройка) |
| `images/` | образы AmneziaWG (userspace), zapret, MTProxy |
| `config/` | шаблон Caddy, мост sing-box, список «мимо VPN» (`direct.json`: Steam/Valve/CS2, STALZONE) |
| `data/` | создаётся установщиком: все секреты и состояние (**не коммитить**) |
